Engineered for Zero-Path-Change Portability

Instead of fragile symlinks inside /Volumes that break diskarbitrationd, DiskTwin switches volume labels by immutable APFS Volume UUIDs.

UUID-Bound Chameleon Mount

When you switch to Road Mode, DiskTwin safely ejects your External SSD and renames the internal MicroSD to Main 1TB via diskutil. Every IDE, Antigravity workspace, Python virtualenv, and media library resolves /Volumes/Main 1TB natively.

Thermal & SLC Cache Pacing

Monitors physical block writes on the SDXC controller via iostat -Id. Every 35 GB written (configurable), DiskTwin pauses rsync with SIGSTOP and flushes kernel buffers so the MicroSD folds its SLC cache and drops temperature before resuming.

Road-Work Safety Lock

Entering Road Mode activates a persistent lock that blocks scheduled background syncs from overwriting files you edited on the road. Returning to Desk Mode prompts you to sync newer road edits back to your primary SSD first.

Self-Bootstrapping App & CLI

Launching /Applications/DiskTwin.app for the first time automatically installs ~/.disk-twin/, configures macOS flash anti-wear flags (.metadata_never_index & .fseventsd/no_log), and registers the background launchd schedule. 

# Check live hardware UUID status, mount points, and Road Lock state
~/.disk-twin/disk_twin.py status

# Run a manual thermal-paced sync (Main 1TB -> MicroSD 1TB)
~/.disk-twin/disk_twin.py sync

# Switch to Road Mode (sync recent changes, eject SSD, mount MicroSD as /Volumes/Main 1TB)
~/.disk-twin/disk_twin.py to-road --sync-first

# Return to Desk Mode (sync newer road changes back to SSD, restore /Volumes/MicroSD 1TB)
~/.disk-twin/disk_twin.py to-desk --sync-back
